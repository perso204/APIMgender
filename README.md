Welcome to our project on current practices related to distinguishability in actor-partner interdependence models (APIMS).

The contents of this repo include the study codebook, 
analytic code, 
the search terms that were used and created in consultation with a university librarian, 
the study preregistration which is available on OSF,
and the data
  data related to screening articles for elibibility (APIM_Screening_AP and APIM_Screening_SH),
  each coders' spreadsheet for data extraction and prior to resolving discrepancies (Extraction_SH, Extraction_EC, Extraction_AP, Extraction_AB),
  the compiled dataset after resolving discrepancies (Extraction_compiled)
  practice coding during the codebook development (Codebookd_development_practice). This is 5 studies published prior to 2025 not included in the manuscript, used only to develop a working coding manual
